# 後續表面

P0 不交付這些階段。順序固定，避免 P0 預留第二條資料路徑或可呼叫的寫入。

| 階段 | 使用者看見的結果 | 邊界 |
| --- | --- | --- |
| P1 對談查資料與產表 | 一句話變成一個具名連線、一個唯讀工具、一組等值篩選；結果是表與匯出 | 執行仍走這組工具 |
| P2 拖拉範本設計 | 元件與參數組成範本；可依欄位建議元件與繫結 | 範本只存版面與繫結，不存資料列 |
| P3 對談套版 | 一句話選定連線、範本與參數；人確認後才填入查詢結果 | 依賴 P1 與 P2 |
| 結構說明 | 用業務語言描述表與欄位 | 不另發 SQL |
| 結果敘事 | 摘要與異常提示 | 數字只來自該次工具結果 |
| 跨來源簡報 | 多個具名連線各查一次，再寫成一份簡報 | 不新增跨廠商 SQL planner |
| 寫入提案 | 草擬新增或更新；人確認後才執行 | 在此之前關閉工具維持關閉 |

P1 起若需要語言模型，使用編譯後的 Python 側車，由 C# 啟動。側車可以把一句話收成連線名稱、唯讀工具與等值篩選，依欄位建議範本元件，或依已返回的列寫摘要。側車不組 SQL、不開連線、不執行查詢、不保存連線字串或業務列，也不在 C# 拒絕時改走 `sql`。C# 先確認工具屬於廣告清單、連線名稱已登記，才執行。側車失敗時資料層沒有副作用。

P0 沒有側車進程，也沒有範本檔。側車的編譯產物、呼叫方式、逾時與版本，以及範本檔格式與設計器所在的前端，都尚未決定，且不影響 P0。

資料分類標籤與正式授權模型尚未決定。在決定之前，業務列不寫進稽核、不外送。
