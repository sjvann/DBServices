# 檢視與報表

## Why

二代平台的資料已由既有 ETL 寫入待轉資料庫。缺的不是再疊一個預覽、畫布與交談共用的工作台，而是三種人各自做完一件事：系統分析師把表結構定義成 MCP 叫得到的檢視，報表設計師把版面存成樣式範本，終端使用者用語句把那筆檢視填進版面。檢視回答業務問題，樣式只負責版面，交談只負責填進版面。連線字串留在伺服器。

## Capabilities

- **CAP-9**
  - **intent:** 已登入且持有該入口的操作者才能打開該站；管理員能建立操作者，並指派或移除系統分析師、報表設計師、終端使用者入口。
  - **success:** 沒有註冊端點。未帶有效工作階段的請求不回傳檢視、樣式範本、生成紀錄或業務列，也不呼叫 MCP。非管理員不能建立操作者，也不能變更入口。同一人可同時持有多個入口。沒有該入口時拒絕，不建立檢視、不修改樣式、不產生動態報表，讀列次數為 0。持有哪個入口就只出現該站，三站不收成同一套導覽。一人多個入口時整頁換站；只有一個入口時不出現換站。儲存裡零個操作者時恰好建立一個管理員；已有操作者後不再讀初始設定。缺初始密碼且零個操作者時，不提供三個入口。畫面不能建立第二個管理者，也不能把操作者改成管理者。產品介面不讀他人的私有生成紀錄。

- **CAP-10**
  - **intent:** 系統分析師能依二代平台的表結構定義一筆檢視並發布；發布之後，MCP 目錄才出現它。
  - **success:** 這份結構不來自待轉資料庫。畫面上沒有連線字串，沒有自由 SQL，也不對來源庫做新增、更新或刪除。沒有資料表時清單是空的。一筆檢視含名稱、目的、來源表、關聯、輸出欄與參數；參數只有欄位與標籤。只有一張來源表時不必有關聯。兩張以上時，每一段要麼是外鍵，要麼是分析師接受的關聯；否則拒絕保存，既有定義不變，不產生笛卡兒積。定義沒有業務列與連線字串。名稱在目錄內不重複，比對不區分大小寫。未發布的檢視不在目錄；目錄是空的時候，不改列資料表工具。目錄的名稱集合等於已發布檢視的名稱集合。樣式繫結穩定 `id`，不繫結名稱。仍被樣式引用時不能刪除、不能取消發布，也不能改名稱、輸出欄、參數、來源表或關聯；目的可以改。發布與呼叫都不在來源庫建立檢視。文件與路由見 `surfaces.md`。

- **CAP-11**
  - **intent:** 報表設計師與終端使用者能把恰好一筆已發布檢視排成由上到下的樣式範本，標成私有或共享，存進同一座樣式庫。
  - **success:** 區塊只有標題、文字、參數、資料表。可加入、重排與刪除。拖曳、上移與下移只改變順序。不保存座標、業務列、連線字串、具名連線與參數值。建議不含業務列與參數值；至少一個資料表區塊的欄名全集等於該檢視的輸出欄，並為每個已宣告參數各有一個參數區塊。未知欄名不能接受。忽略或建議失敗不改既有區塊。接受才把區塊加到末尾；修改後再接受，採用修改後的版本。重新開啟時順序與繫結與上次保存相同，不需要連線也能看版面。擁有者可改內容與共享範圍，其他人不能。私有只有擁有者可讀。共享對持有報表設計師或終端使用者入口的人可讀。終端使用者把版面存回樣式庫時不呼叫 MCP，新範本的擁有者是該人。欄位見 `workbench-shapes.md`。

- **CAP-12**
  - **intent:** 終端使用者能用語句套用自己可讀的樣式範本；就緒後直接產生動態報表，列來自所綁的那一筆已發布檢視。
  - **success:** 候選只含此人可讀的樣式：自己擁有的，以及共享的。指定不可讀樣式的識別時拒絕，讀列次數為 0。語句含樣式名稱才進入候選；含參數欄位或標籤時，其後第一個不以空白拆開的詞為值；對不到的不補猜，也不從語句取出連線名稱。未就緒、候選超出本次輸入，或缺少參數時不呼叫，讀列次數為 0，並指出是多筆、缺哪個欄位或標籤，或對不到。改選候選不讀列。時間範圍只有在同一個詞能當某個參數的一個等值時才成為值。沒有確認清單。就緒後恰好呼叫該檢視一次，參數是純量，且屬於該檢視已宣告的參數。人不選擇連線。恰有一筆組態完整的具名連線才呼叫；否則顯示可讀錯誤，讀列次數為 0。不呼叫資料表工具，也不另發計數。空列是成功，不是錯誤。呼叫失敗時不產生動態報表，不用舊列湊成成功報表，也不改樣式與生成紀錄。比對不啟動模型。狀態與輸入見 `workbench-shapes.md`。

- **CAP-13**
  - **intent:** 終端使用者能把這次動態報表存成生成紀錄並指定私有或共享；匯出與列印只用目前這份報表，或已開啟的生成紀錄。
  - **success:** 紀錄含擁有者、共享範圍、當時的區塊順序與文字、該次欄與列、純量參數，不含連線字串。再開顯示保存的那一份，不回讀樣式，也不呼叫 MCP。私有只有擁有者可讀。共享對持有終端使用者入口的人可讀。其他人不能修改或刪除。離開這次報表，或同一人產生下一份時，尚未寫入的那份不能再匯出。PDF、列印與 CSV 的數字和文字等於所開啟的那一份，包含空結果，且不發出新的 MCP 呼叫。同一份連續匯出，業務數字相同。PDF 預設 A4，換頁以區塊為界，不對位預印表單。

## Constraints

- 工作台不建立 `IDbService`、不呼叫 `QuerySession`，也不修改公開的 `IDbService`、`IDbServiceAsync`、`DbServices.Core`、`FunctionRegistry`、Provider，以及既有 REST 與 GraphQL 的路徑和查詢形狀。
- 登入、入口、樣式、語句比對、動態報表與生成紀錄只經過 `Workbench.Core`。Blazor 在進程內呼叫。Avalonia 只經工作台 HTTP 進入同一組端口。控制器不另寫業務判斷。
- 兩個殼與 `Workbench.Web` 不參考配接器、`DbServices.Mcp`、`DBService`、Provider 或 `Microsoft.Extensions.AI`，也不持有 MCP 或 Web API 的基底網址。Core 不參考 ASP.NET、Avalonia 與模型套件。
- 部署恰好一個 `Workbench` 進程。只有它開啟工作台 SQLite，並在記憶體持有工作階段與尚未保存的動態報表。Avalonia 不嵌入 Blazor、不開啟該檔。不另開實例分攤這些物件。殼的組態只有工作台基底網址。
- 工作階段是宿主記憶體中的一筆 `sessionId` 與操作者 `id`。cookie 與 bearer 都只帶 `sessionId`。登出刪除該筆，兩殼同時失效。進程重啟後清空。
- 選項類別不宣告連線字串。`AllowedHosts` 出貨值為 `*`。TLS 由部署終止。某個業務連線失敗不停止宿主，其他檢視仍可呼叫。
- 動態報表的列只來自一次已發布檢視呼叫，並以操作者 `id` 填 `X-DBServices-Caller`。不呼叫 `tables`、`fields`、`get`、`query`、`count`、`exists`、`insert`、`update`、`delete`、`sql`，也不在 `McpService` 加登入。工具引數是頂層 `connectionId` 與該檢視的純量參數，沒有 `filters`，也不把參數拼進 SQL。
- 恰有一筆組態完整的具名連線才送出 `connectionId`。零筆或多筆不呼叫，讀列次數為 0。三個入口不渲染連線清單，人不能輸入連線字串。
- 檢視定義只在 `DbServices.Mcp`。工作台不另存一份目錄。`McpService` 不開啟工作台 SQLite，也不做第二套登入。目錄寫入要求 `Workbench:CatalogKey`，並拒絕空白的 `X-DBServices-Caller`。MCP 工具路由不讀該鍵，工具呼叫仍依資料平面：空白呼叫者記為 anonymous 且呼叫仍執行。工作台自己送出的呼叫帶操作者 `id`，不以 anonymous 呼叫。
- 仍被樣式 `viewId` 引用時，`Workbench.Core` 先拒絕刪除、取消發布與結構變更，再呼叫目錄。不在來源庫執行 `CREATE VIEW`。沒有連通路徑時不保存，不產生笛卡兒積。
- 工作台 SQLite 只放操作者、入口指派、樣式範本與生成紀錄。不放檢視定義、業務連線字串與模型金鑰。樣式不含業務列、參數值與連線名稱。
- 沒有確認清單。語句未就緒不呼叫 MCP。就緒後恰好呼叫一次。失敗不寫生成紀錄，不用舊列湊成成功報表。匯出、列印與存回樣式庫都不發出新的 MCP 呼叫。
- 語句比對在 Core，不啟動側車。輸入只有語句與此人可讀樣式的摘要。不從語句補猜連線。宿主重算狀態，不以比對步驟自報的狀態當作可以呼叫的依據。候選超出本次輸入則整份作廢，讀列次數為 0。
- 三個入口不讀寫模型設定、不測試連線、不提供詞庫編輯、不渲染取數軌跡，也不寫第二份 MCP 稽核，不實作稽核保留天數。
- 區塊 `type` 只許 `title`、`text`、`parameter`、`table`。`order` 從 0 連續。不保存 x、y、寬與高。沒有 `count` 區塊。筆數若要出現，必須是該檢視的一個輸出欄。
- 授權單位是入口與共享範圍。不做資料表級或欄位級授權。只有管理員建立操作者與變更入口。私有只對擁有者可讀。共享樣式對持有報表設計師或終端使用者入口的人可讀。共享生成紀錄對持有終端使用者入口的人可讀。只有擁有者能改內容或共享範圍。
- 畫面不能建立第二個管理者，也不能把操作者改成管理者。語句欄的 Enter 等於送出語句。樣式區塊除了拖曳，必須有上移與下移。對話框只疊一層。
- 工作台自己的錯誤是穩定英文蛇形碼加繁體中文訊息。MCP 的 `code` 與 `message` 原樣顯示。不重算列，不把空列改成錯誤。訊息不含連線字串、金鑰、密碼與堆疊秘密。操作者看得到的文字與空狀態使用繁體中文。
- 明文密碼不寫入 SQLite 與日誌。三個入口的存放在營運者自己的環境，不寫進來源庫，也不預設外送。不新增健康檢查、指標或第二條日誌管線。
- 規劃期的表結構不得取自待轉資料庫，也不得為了這份結構讀業務列。Web API 不用來產生動態報表。

## Non-goals

- 把三個入口收成一個報表工作台，或三站共用一條功能軌。
- 交付 ETL，或從這三個入口改寫二代平台來源庫的結構。
- 第二套查詢引擎、自由 SQL、區間條件、跨表組合，或跨廠商 SQL planner。
- 在入口、檢視定義、樣式範本或錯誤中放置連線字串，或把業務列寫進檢視定義與樣式範本。
- 讓人選擇 MCP、Web API 或具名連線。
- 像素級套印：預印表單、分欄帶、子報表、絕對座標。圖表、結果敘事、跨來源簡報、寫入提案。
- 把 GraphQL 或 CLI 當作這三個入口的資料通道。
- 以綁定某個模型廠商，或把側車啟動，作為語句解析的完成條件。關鍵字規則達到 CAP-12 即算該行為完成。
- 這一輪啟動側車、提供詞庫編輯、渲染取數軌跡，或把檢視先落地成另一份資料表。
- 企業目錄、SSO、公開註冊，以及資料表級或欄位級授權。
- 把側車改回編譯 Python。若要改回，先改資料平面附錄與本規格的側車決定。
- 用常用項目只保存叫法，並在再開時重新查詢。
- 修改資料平面 P0 的工具契約或公開資料存取簽名。

## Success signal

發布一筆檢視前後，MCP 目錄的名稱集合分別等於當時的已發布檢視；就緒後的那次呼叫使用這筆檢視並得到列。抽樣的樣式範本找不到業務列與連線字串，抽樣的生成紀錄找不到連線字串。一句尚未就緒的語句，MCP 讀列次數是 0；就緒後實際呼叫的檢視與參數等於該筆樣式。開放自由 SQL、把資料表工具放進目錄、讓人選擇連線、把三站收成同一套導覽、圖表、預印表單對位，或綁定某個模型廠商，都不算達成。

## Open Questions

- 規劃期讀取二代平台表結構的通道仍未定。定案前不得用待轉資料庫的 `GET /meta` 充當，也不得為了這份結構讀業務列。
- MCP 稽核保留天數仍未定。三個入口不另定，也不實作保留政策。
- CSV 的具體寫法未定。匯出只使用目前這份動態報表或已開啟的生成紀錄，選定時不得再查資料。PDF 已定為預設 A4。
- 零筆或多於一筆具名連線時，工作台自己的錯誤碼拼法尚未指定。行為已定：不呼叫，讀列次數為 0，訊息可讀且不含連線字串。
