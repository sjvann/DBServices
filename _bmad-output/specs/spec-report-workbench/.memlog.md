- (capability) CAP-1 已登入才可用；管理員建立操作者、建立與重新命名群組、指派 design 或 view。沒有公開註冊。成功：未登入不回傳資料也不呼叫 MCP；非管理員不能建帳或改角色；design 含檢視；移除角色後清單不再含該群組。
- (capability) CAP-2 選擇 MCP 或 Web API，列出名稱與 ServerType，瀏覽表與欄。成功：無連線字串；Web 只有 default；省略 includeView 與宿主相同；fields 至少含名稱、型別、主鍵、不可為空；換 ServerType 不換工具名與參數鍵；單一連線失敗不停止宿主，也不把先前成功列蓋成未處理例外。
- (capability) CAP-3 確認後以等值篩選預覽列，MCP 另可計數；沒有寫入與自由 SQL。成功：結果原樣、空列不是錯誤；Web 只許零鍵或單鍵 GET，兩個以上篩選或自算筆數都拒絕且不發送。
- (capability) CAP-4 每次結構與填數呼叫留下畫面軌跡，MCP 成功 query 對得上該次稽核。成功：不含列與連線字串；稽核呼叫者等於操作者 id；execution_failed 不顯示部分列；軌跡不進 SQLite。
- (capability) CAP-5 五種元件、由上到下的畫布、依 fields 的建議、群組範本庫。成功：不存座標、列、連線與參數值；未知欄不能接受；忽略或失敗不改畫布；修改後接受採用修改版；無權限讀取填數次數為 0。
- (capability) CAP-6 語句成為意圖，就緒才列出填數呼叫，確認後實際集合與清單相同。成功：未就緒、作廢候選、表面能力不符或任一筆失敗時不部分執行；填數次數在拒絕時為 0；解析失敗不改範本、常用與規則。
- (capability) CAP-7 常用項目只存叫法，再次開啟用範本目前版面並重新確認；匯出與列印只用該次快照。成功：不讀舊列、不發新填數；離開或下次確認後舊快照失效；同一快照兩次匯出的業務數字相同；PDF 預設 A4，換頁以元件為界。
- (capability) CAP-8 管理員設定一份雲端或本地模型，並可先測試連線。成功：讀取不回金鑰值；探測不改 model.json、不帶回模型內文；失敗不改範本與規則且填數次數為 0；enabled 為 false 時只走關鍵字。
