# 詞彙

本檔的詞給 CAP 與其他配套使用。實作名稱可以不同，語意以這裡為準。

- **檢視** — 一筆模組。具名，有目的、來源表、關聯、輸出欄與參數。定義在檢視目錄。已發布之後，MCP 把它包成一個可呼叫工具。不是畫面區塊，也不是權限名稱。
- **檢視目錄** — 檢視定義的唯一存放。在 `DbServices.Mcp`，不在工作台 SQLite。`McpService` 不依賴工作台進程就能列出已發布檢視。
- **模組設計工具** — 系統分析師的入口。建立、修改、發布檢視。
- **樣式範本** — 名稱、所綁的恰好一筆檢視、由上到下的區塊、共享範圍、擁有者。只含版面與繫結，不含業務列、參數值與連線字串。
- **樣式庫** — 工作台 SQLite 裡的全部樣式範本。報表設計師與終端使用者共用這一座庫。
- **AI 報表設計工具** — 報表設計師的入口。引用已發布檢視並保存樣式範本。
- **Chat 報表生成器** — 終端使用者的入口。交談、產生動態報表、保存生成紀錄，以及把版面存回樣式庫。
- **動態報表** — 一次就緒交談產生的報表。版面是當時的區塊，列是該次對所綁檢視的呼叫結果。尚未寫入生成紀錄時，只在宿主記憶體。
- **報表生成紀錄** — 一次動態報表的保存：擁有者、共享範圍、當時的區塊與文字、該次的欄與列、純量參數。不含連線字串。再開不重新讀取。
- **共享範圍** — `private` 或 `shared`。標在樣式範本與生成紀錄上。私有只有擁有者可讀。共享樣式對持有報表設計師或終端使用者入口的人可讀。共享生成紀錄對持有終端使用者入口的人可讀。只有擁有者可改內容或改範圍。
- **入口** — 一個人被允許打開的站。`analyst` 是系統分析師，`designer` 是報表設計師，`enduser` 是終端使用者。各站只做該站的事。
- **操作者** — 可登入的人，有穩定 `id`。呼叫 MCP 時這個 `id` 寫入 `X-DBServices-Caller`。
- **管理員** — `admin` 為真的操作者。可建立操作者並指派入口。安裝後畫面只能有這一個管理者。
- **區塊** — 樣式裡由上到下的一項。只有標題、文字、參數、資料表。
- **參數** — 檢視已宣告的一個等值篩選。樣式只保存欄位與標籤。值由交談在就緒時提供，是純量。
- **就緒** — 恰好一筆此人可讀的樣式範本，且該範本每個參數都有一個純量值。
- **關鍵字** — 從語句抽出的樣式候選與參數值。不啟動模型。
- **待轉資料庫** — ETL 寫入的資料庫。三個入口都不讓人選擇它的連線，也不用它的表結構充當規劃期清單。
- **web API** — 待轉資料庫既有的讀取通道。這一輪不用它產生動態報表，也不用它的 `GET /meta` 充當規劃期結構。
- **MCP** — 已發布檢視的呼叫包裹。人在畫面上不選擇它。
- **工作階段** — 宿主記憶體中的一筆 `sessionId` 與操作者 `id`。瀏覽器 cookie 與桌面 bearer 都只帶 `sessionId`。
- **viewId** — 樣式指向目錄裡檢視的穩定 `id`。不是工具名稱。工具名稱是檢視的 `name`。
