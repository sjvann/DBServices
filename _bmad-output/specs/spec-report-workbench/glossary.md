# 詞彙

本檔的詞給 CAP 與其他配套使用。實作名稱可以不同，語意以這裡為準。

- **報表工作台** — 已登入操作者在此預覽資料、設計範本、用語句套版、管理常用項目、匯出與列印。
- **操作者** — 工作台儲存裡的一個可登入的人，有穩定 `id`。呼叫 MCP 時這個 `id` 寫入 `X-DBServices-Caller`。
- **管理員** — 可建立操作者、建立與重新命名範本群組、指派角色的操作者。
- **設計角色** — 某範本群組上的 `design`。可在該群組建立、修改、刪除與移出範本。讀取時視同檢視角色。
- **檢視角色** — 某範本群組上的 `view`。可列出、套用與預覽該群組的範本，不能修改範本。
- **具名連線** — 伺服器組態中的一筆連線。工作台只使用名稱與 `ServerType`。
- **ServerType** — `Sqlite`、`SqlServer`、`MySQL`、`Oracle`、`PostgreSQL` 之一。Web API 那一筆的顯示名稱是 `default`，其 `ServerType` 來自工作台組態，不來自 WebService 組態檔。
- **取數表面** — 這次讀資料所走的服務。v1 只有 `mcp` 與 `web`。
- **等值篩選** — 欄位名稱對到一個純量（字串、數字、布林或 null）。不是 SQL 片段，也不是區間。
- **結構呼叫** — 取得連線清單、資料表名稱或欄位的呼叫。不回傳業務列。
- **填數呼叫** — 會回傳業務列或計數的呼叫。MCP 上是 `query` 與 `count`。Web API 上是讀取資料表列的 GET。
- **元件** — 畫布上的一個區塊。v1 只有標題、文字、參數、資料表、計數。
- **畫布** — 一份範本的元件序列，由上到下排列。拖曳只改變順序。不記錄絕對座標。
- **繫結** — 元件指向的資料表名稱與欄位名稱。
- **參數** — 一種元件。綁定一個欄位，執行時提供一個等值篩選的值。範本只保存欄位與標籤，不保存值。
- **報表範本** — 名稱、所屬群組、畫布。只含版面、繫結與參數定義，不含資料列、連線字串與具名連線。
- **範本群組** — 範本的一個集合。每個範本恰好屬於一個群組。
- **範本庫** — 工作台儲存裡的全部群組與範本。操作者只看見自己有角色的群組。
- **建議** — 尚未寫入畫布或尚未執行的提案。設計器的建議是元件與繫結。交談的建議是意圖。
- **語句** — 操作者輸入的一段自然語言。
- **意圖** — 語句的解析結果：零個以上具名連線、零個以上範本、零個以上等值篩選。
- **確認** — 操作者明確同意執行一組已經列明的填數呼叫。活資料預覽的查詢按鈕、範本預覽按鈕、交談套版的確認按鈕，都是確認。
- **預覽** — 確認之後，用該次填數呼叫的結果填入畫面。
- **預覽快照** — 該次預覽畫面上的數字與列。匯出與列印使用這份快照。它不是工作台儲存裡的紀錄。
- **常用項目** — 操作者保存的一次叫法：名稱、範本、取數表面、具名連線、參數值。不含版面複本，不含資料列。
- **常用清單** — 一個操作者擁有的常用項目集合。其他操作者不可讀。
- **取數軌跡** — 畫面上一次呼叫的紀錄：操作者識別、具名連線、工具或請求種類、等值篩選、列數或計數或錯誤碼。不寫入工作台 SQLite。
- **工作台儲存** — 工作台自己的帳號、群組、角色、範本、常用項目與關鍵字規則。不是業務庫。
- **工作階段** — 宿主記憶體中的一筆 `sessionId` 與操作者 `id`。瀏覽器 cookie 與桌面 bearer 都只帶這個 `sessionId`。
- **關鍵字規則** — 工作台儲存裡的一筆說法，對到連線、範本或參數欄名。不含參數值。
- **模型側車** — `DbServices.ModelSidecar`。由工作台啟動的獨立行程，唯一建立 `IChatClient` 的地方。不是常駐服務，也不是 Python。
