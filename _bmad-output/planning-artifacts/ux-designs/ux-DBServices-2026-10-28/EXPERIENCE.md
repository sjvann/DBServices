# DBServices 文件站 — Experience Spine

`DESIGN.md` 是視覺身份。本檔是閱讀與導覽行為。衝突時以這兩份骨架為準。文章裡的產品名詞維持現稿。

## Foundation

[ASSUMPTION] 單一網站，DocFX modern。桌面閱讀為主，手機仍要能打開目錄、搜尋與主題。沒有另做元件庫。視覺差值只寫在 `DESIGN.md`。

這是公開開源文件。讀者是外部工程師。文案不是受管制申報用語。

## Information Architecture

| 表面 | 從哪裡進入 | 用途 |
|---|---|---|
| 首頁 | 站台開啟、頂欄「首頁」 | 一句話說明產品，進入手冊與 API |
| 入門 | 頂欄、首頁卡片 | 安裝與第一個查詢 |
| 指南 | 頂欄、首頁卡片 | CRUD、查詢、事務、遷移、安全、效能 |
| 架構 | 頂欄、首頁卡片 | 分層與連線 |
| CLI | 頂欄、首頁卡片 | `dbsql` |
| Web API | 頂欄、首頁卡片 | REST 與 GraphQL |
| MCP | 頂欄、首頁卡片 | 外部 Agent 的 Discovery |
| 報表工作台 | 頂欄、首頁卡片 | 檢視、樣式、一句話報表 |

頂欄是這十個入口。左側目錄是目前章節。右側是本頁標題。沒有新增頁面。

## Voice and Tone

微文案沿用現有句子。品牌語氣不在這次改寫。

| 維持 | 這次不做 |
|---|---|
| 「三分鐘上手」 | 改成口號或驚嘆句 |
| 「一個介面對齊五種資料庫」 | 加裝飾用的科技形容詞 |
| 搜尋框維持 DocFX 的「Search」 | 自造搜尋提示 |
| 目錄、上一篇、下一篇維持 DocFX 用語 | 改導覽標籤 |

## Component Patterns

行為。外觀在 `DESIGN.md` 的 Components。

| 元件 | 出現位置 | 行為 |
|---|---|---|
| 頂欄 | 每一頁 | 點名稱回首頁。作用中章節保持可辨。搜尋打字後跳出結果，Esc 或點結果離開。 |
| 左側目錄 | 桌面常駐；窄螢幕為抽屜 | 點項目換頁。窄螢幕打開後選擇即關閉抽屜。 |
| 本頁目錄 | 桌面文章右側 | 點標題捲到該節。捲動時標出目前節。 |
| Hero 與卡片 | 首頁 | 整張卡片可點。主按鈕進快速開始，幽靈按鈕進動態報表。 |
| 程式碼區塊 | 指南與 API | 可選取、可複製。DocFX 的複製按鈕留著。 |
| 主題切換 | 頂欄 | light / dark / auto。選擇記在這個瀏覽器。 |

## State Patterns

| 狀態 | 表面 | 處理 |
|---|---|---|
| 第一次開啟 | 任一頁 | 跟系統深淺色。沒有強制夜讀。 |
| 搜尋無結果 | 搜尋結果 | 用 DocFX 原文：「找不到結果」那句，不另寫。 |
| 目錄很長 | 左側目錄 | 目錄自己捲動，頂欄黏住。 |
| 表格比欄寬 | 文章 | 文章區橫向捲動，不把整頁撐破。 |
| 窄螢幕 | 全站 | 目錄收進抽屜。首頁按鈕改成直向、拉滿。 |

## Interaction Primitives

滑鼠為主。鍵盤沿用瀏覽器與 DocFX：Tab 走到連結、按鈕、搜尋；Enter 開啟；Esc 關閉抽屜與搜尋。焦點環用訊號色，2px，偏移 2px。

頂欄黏在視窗上緣，長文往下讀時仍能換章或搜尋。

## Accessibility Floor

- 正文、連結、按鈕字對比至少 4.5:1。這次選色已超過。
- 主按鈕點擊高度至少 44px。
- 焦點必可見。不只靠顏色標出作用中項目，目錄還有左側軌。
- `prefers-reduced-motion: reduce` 時拿掉過渡。
- 主題切換不移除。圖示按鈕維持既有的 accessible name。

## Key Flows

**林可恩，後端，晚上在筆電查 Session 怎麼接到 PostgreSQL。**

1. 她打開站台。系統是深色，所以她看到夜讀面：冷底、青色連結。
2. 頂欄進「入門」，左側目錄點快速開始。
3. 她掃到程式碼區塊。區塊像終端，左邊一條青色軌，範例可以直接複製。
4. **高潮**：她複製範例，沿本頁目錄跳到下一節，再從頁尾的下一篇進指南。青色只標出這條路，其餘文字保持可長讀。
5. 她改查 API 參考。同一套頂欄、目錄與程式碼，不換成另一種視覺。

## Responsive & Platform

[ASSUMPTION] 只有這個網站。不為列印重排，列印時拿掉 hero 格線即可。桌面三欄；1100px 以下首頁卡片兩欄；640px 以下一欄，目錄改抽屜。

## Inspiration & Anti-patterns

儀器面板：髮絲、等寬標籤、終端程式碼、少量青色。

不做：霓虹光暈、全頁格線、掃描線動畫、把句子改成口號、強迫每位讀者進入深色。
