## 改寫

| 計畫 | 骨架 |
|---|---|
| 左樹展開到包、表、欄 | 樹只到資料表。欄位只出現在畫布表卡 |

| JOIN 只有 inner 與 left | 增加 right join |
| 屬性面板收納筆數、DISTINCT、WHERE、GROUP BY、彙總、HAVING、ORDER BY，位置寫「畫布旁」 | 同樣是整份查詢的屬性，明確放在畫布右邊。這輪口語是筆數、不重複、篩選、分組、彙總、排序 |
| 工具列有圖像／SQL 切換，SQL 是另一頁 | 畫布與 SQL 同時呈現。SQL 在畫布正下方。沒有切換 |
| 表卡上的勾選沒有寫初值 | 剛拖上畫布時只勾主鍵 |
