# 檢視與報表 — Experience Spine

`DESIGN.md` 是視覺身份。本檔是行為。衝突時以這兩份骨架為準，不以舊的工作台畫面或口頭補充為準。

產品名詞與 [PRD](../../prds/prd-DBServices-2026-10-12/prd.md) 第 3 節相同。本檔不另造同義詞。

## Foundation

兩個殼、同一套行為：瀏覽器裡的 Blazor，以及 Avalonia 桌面殼。Avalonia 不嵌入 Blazor。沒有命名的 UI 元件庫。視覺差值只寫在 `DESIGN.md`。

這是內部營運工具。旅程裡出現銷貨與薪資，資料敏感。產品不是對外申報系統。

三個入口各自一整頁：模組設計工具、AI 報表設計工具、Chat 報表生成器。不把三站收成同一條功能軌。帳號與入口分開。建立帳號時只有顯示名稱與登入秘密。安裝完成後恰好一個管理者帳號，在「入口指派」把入口加到別的帳號上，也可以加到自己的帳號上。畫面上不能再建立第二個管理者。一人可以同時持有多個入口。

介面文字、空狀態與這三個入口自己產生的錯誤使用繁體中文。MCP 已回傳的訊息維持宿主原文。錯誤是穩定代碼加繁體中文訊息。

## Information Architecture

| Surface | Reached from | Purpose |
|---|---|---|
| 登入 | 未持有工作階段時 | 取得工作階段。沒有註冊 |
| 換站 | 登入後，且入口多於一個 | 換成另一個入口的整頁。不是三站功能清單 |
| 檢視清單 | 系統分析師入口 | 列出自己看得到的檢視。進入一筆定義 |
| 檢視定義 | 檢視清單的一列 | 看二代平台的表與欄，寫目的、來源表、關聯、輸出欄、參數，發布 |
| 樣式清單 | 報表設計師入口，以及終端使用者要存回樣式時 | 列出可讀的樣式範本。擁有者才能改 |
| 樣式編輯 | 樣式清單中自己擁有的一列 | 引用一筆已發布檢視，由上到下排區塊，指定私有或共享 |
| 交談 | 終端使用者入口 | 送出語句，看見候選或缺少的參數。就緒後同一頁產生動態報表 |
| 動態報表 | 交談在就緒並送出之後 | 這一頁的本文。匯出 PDF、列印、匯出 CSV |
| 生成紀錄 | 終端使用者入口 | 自己的私有紀錄，以及共享紀錄。再開不重新讀取 |
| 帳號 | 僅管理者帳號 | 建立與列出操作者。表單沒有入口 |
| 入口指派 | 僅管理者帳號 | 選一個已存在的帳號，再指派入口 |

一人只有一個入口時，登入後直接進入該站，不經過換站。沒有任何入口、也不是管理者的帳號，登入後只有一句：「尚未指派入口。」

檢視定義的左側是該站自己的清單，右側是定義。樣式編輯同樣並排。這條欄寬用 `{spacing.rail}`，裡面沒有其他站的目的地。

對話框只疊一層。直接指定沒有入口的表面時拒絕，不建立檢視，也不修改樣式範本。

畫面參考：`mockups/key-view.html`（檢視定義）、`mockups/key-style.html`（樣式編輯）、`mockups/key-chat.html`（交談，尚未就緒）。骨架與畫面衝突時，以骨架為準。

## Voice and Tone

微文案。品牌姿勢在 `DESIGN.md` 的 Brand & Style。用詞與 PRD 相同：檢視、模組設計工具、樣式範本、AI 報表設計工具、Chat 報表生成器、動態報表、報表生成紀錄、共享範圍、入口、就緒。

| Do | Don't |
|---|---|
| 「這裡還沒有動態報表。」 | 「預覽即將為你準備好！」 |
| 「沒有符合的列。」 | 「找不到資料，請再試一次。」 |
| 「沒有資料表。」 | 「這裡空空如也。」 |
| 「還缺年月。」 | 「我不太確定你的意思。」 |
| 錯誤碼保持原樣，人話另起一行 | 把錯誤碼翻譯成另一個代碼 |

## Component Patterns

行為。外觀在 `DESIGN.md` 的 Components。

| Component | Use | Behavioral rules |
|---|---|---|
| commit-button | 檢視定義、樣式編輯、交談 | 標籤只限：發布、儲存樣式、送出語句。發布寫入已發布狀態。儲存樣式不讀業務列。送出語句只做關鍵字；就緒時這一次送出才讀列並產生動態報表。未就緒時讀列次數是 0 |
| secondary-button | 各站 | 接受建議、忽略建議、上移、下移、存成生成紀錄、存回樣式庫、匯出 PDF、列印、匯出 CSV。接受建議只把區塊加到末尾。匯出不重新讀取。存回樣式庫不重新讀取 |
| style-block | 樣式編輯 | 四種：標題、文字、參數、資料表。拖曳只改變由上到下的順序。每個區塊另有上移、下移。沒有座標。刪除後保存結果不再含該區塊。非擁有者只能看 |
| report-well | 交談產生之後的動態報表 | 沒有這次報表時沒有業務列。產生成功後顯示該次的列，空結果也是結果。失敗時這一區只有該次錯誤，不用舊列湊成成功報表。已存的生成紀錄不因這次失敗而改寫 |
| error-block | 呼叫失敗、拒絕保存、拒絕開啟 | 顯示代碼與人話。不含連線字串、密碼、金鑰。MCP 代碼原樣 |
| account-row | 帳號 | 一列一個操作者，只顯示名稱。建立與編輯都不收集入口。不能把操作者改成管理者 |
| entry-badge | 入口指派 | 可多選：系統分析師、報表設計師、終端使用者。儲存入口不是送出語句，不讀業務列 |
| intent-status | 交談 | 只顯示就緒、多筆候選、缺少條件。多筆候選時要收到一筆。缺少參數時指出欄位或標籤 |
| visibility-mark | 樣式清單、樣式編輯、生成紀錄 | 文字只會是私有或共享。擁有者可改。其他人不能改這筆的內容，也不能改這個標記 |

## State Patterns

| State | Surface | Treatment |
|---|---|---|
| 未登入 | 任何表面 | 停在登入。不回傳檢視、樣式範本、生成紀錄或業務列 |
| 帳號尚無入口 | 登入後 | 「尚未指派入口。」帳號仍然存在 |
| 非管理者 | 帳號、入口指派 | 不出現。直接進入時拒絕 |
| 只有一個入口 | 登入後 | 直接進入該站。沒有換站 |
| 多個入口 | 換站 | 頁首可換站。換過去是那一站的整頁 |
| 沒有資料表 | 檢視定義 | 「沒有資料表。」 |
| 來源表連不起來 | 檢視定義 | 拒絕保存。既有定義不變。不產生把所有列乘在一起的結果 |
| 檢視已被樣式引用 | 檢視定義 | 不能刪除、不能取消發布，也不能改名稱、輸出欄或參數。目的文字可以改 |
| 沒有動態報表 | 交談 | 「這裡還沒有動態報表。」不下載列來當佔位 |
| 語句未就緒 | 交談 | 多筆候選列出樣式範本；缺少條件指出缺什麼。讀列次數是 0 |
| 沒有符合的列 | 動態報表 | 空結果，不是未處理錯誤 |
| 讀取失敗 | 動態報表上的 error-block | 不產生動態報表。已保存的生成紀錄保持原樣 |
| 多於一筆具名連線 | 送出已就緒的語句 | 可讀錯誤。人不選擇連線。讀列次數是 0 |
| 私有 | 樣式清單、交談候選、生成紀錄 | 只有擁有者看得到 |
| 共享樣式 | 樣式清單、交談候選 | 持有報表設計師或終端使用者入口的其他人可讀、可套用，不能改 |
| 共享生成紀錄 | 生成紀錄 | 持有終端使用者入口的其他人可開啟。開啟的是保存的那份動態報表 |
| 建議含未知欄 | 樣式編輯 | 不能接受。忽略或建議失敗都不改已排好的區塊 |
| 無權限的識別 | 任何站 | 拒絕。讀列次數是 0 |

[NOTE FOR UX] 來源沒有載入中的畫面，也沒有「未儲存變更」的對話。儲存與發布是明確的按鈕。

## Interaction Primitives

- 點按執行動作。會讀業務列的動作只有交談裡就緒後的「送出語句」。
- 拖曳只在樣式編輯的 style-block 上改變上下順序。每個區塊另有上移、下移。
- 換站、改選樣式候選、接受建議、儲存樣式、發布檢視，本身都不讀業務列。發布會讓 MCP 目錄出現該檢視。
- 語句欄的 Enter 等於送出語句。未就緒時不讀列。Esc 關閉最上層對話框。
- 產生成功後，焦點移到動態報表的標題。
- 匯出與列印只吃目前這份動態報表，或已開啟的生成紀錄。
- 再開生成紀錄不讀列。

禁止：三站共用的功能軌、自由座標、自由 SQL、區間條件、圖表、連線字串欄位、在入口裡選擇通道或具名連線、寫入二代平台來源庫、公開註冊、對話框疊兩層、用範例列充填尚未產生的報表。

## Accessibility Floor

行為。對比在 `DESIGN.md` 的 Colors。上移、下移已確認。

- [ASSUMPTION] Blazor 以 WCAG 2.2 AA 為底。Avalonia 用同一閱讀順序、同一控制項名稱，可全鍵盤操作。
- commit-button 的含義除了顏色，還有標籤與 intent-status 文字。錯誤同時有代碼與訊息。
- 拖曳改序不是唯一手段；上移、下移必須在。
- 停用墨對比不足，不能單獨表示原因。
- 焦點順序等於閱讀順序。Esc 關閉最上層對話框。
- 進入動態報表時宣告頁名。頁內的列或錯誤更新用可被讀屏發現的區域。

## Responsive & Platform

| 表面 | 行為 |
|---|---|
| Blazor，寬度 ≥ 1280px | 單一入口的清單與編輯並排 |
| Blazor，1100–1279px | 並排仍在 |
| Blazor，< 1100px | [ASSUMPTION] 不另做手機版。允許橫向捲動，不把區塊順序藏進只有懸停才看得到的地方 |
| Avalonia | 與 Blazor 同一資訊架構。最小視窗 1100×720 |

兩個殼都只有被指派的入口。沒有第三套畫面。

## Inspiration & Anti-patterns

- 拒絕把三個入口排成一條工作台左軌。
- 拒絕自由座標、預印表單、分欄帶、子報表。樣式是順序。
- 拒絕圖表與結果敘事。
- 拒絕在畫面上放置連線字串，或在語句未就緒時把業務列畫出來。
- 拒絕在報表兩站臨時組合檢視。
- 拒絕用「檢視」稱呼一種權限。

[ASSUMPTION] 不借用儀表板的卡片牆，也不借用套印軟體的頁面畫板。

## Key Flows

### UJ-1. 林可把銷貨定義成一筆檢視。

林可是系統分析師。管理者帳號已給她這個入口。她已登入。待轉資料庫的轉置不是她這一步要看的。

1. 她進入模組設計工具，看到二代平台的資料表與欄位。畫面上沒有連線字串。
2. 她建立銷貨月檢視，寫下目的，選來源表與關聯，指定輸出欄與參數「年月」。
3. 她按發布。
4. **高潮：** 這筆檢視出現在已發布清單。未發布前，Chat 報表生成器叫不到它。

失敗：來源表彼此連不起來。工具拒絕保存，清單不變。

### UJ-2. 周寧引用這筆檢視，做成月報樣式。

周寧是報表設計師。銷貨月檢視已發布。她沒有打開模組設計工具。

1. 她進入 AI 報表設計工具，引用銷貨月檢視。
2. 工具依輸出欄與參數提出區塊。她接受，再調整順序，留下標題、文字、綁「年月」的參數，以及一個資料表區塊。
3. 她命名為銷貨月報，共享範圍選共享，按儲存樣式。
4. **高潮：** 她再次打開這筆樣式。畫面上是區塊與繫結。沒有業務列。

失敗：建議裡有這筆檢視沒有的欄。她不能接受。忽略建議不改動已排好的區塊。

### UJ-3. 陳安用語句得到十月的動態報表。

陳安是終端使用者。他沒有另外兩個入口。銷貨月報是共享樣式，參數是年月。

1. 他在 Chat 報表生成器說「銷貨月報，年月 2026-10」，按送出語句。
2. 語句就緒。這一次送出讀取銷貨月檢視，同一頁出現動態報表。
3. 他把這次存成私有的生成紀錄，再匯出 PDF 並列印。
4. **高潮：** 送出前，報表區沒有業務列。送出後，列來自這一次呼叫。隔天他從生成紀錄再開，看到的是當時那一份，不會重新讀取。

失敗：句子對不到樣式，或對不到年月。畫面指出缺什麼。這段交談的讀列次數是 0。

### UJ-4. 私有的留在擁有者，共享的才能被別人套用。

周寧有一筆私有的薪資樣式。陳安有一筆私有的生成紀錄。兩人都已登入。

1. 陳安在交談裡找薪資。周寧打開生成紀錄。
2. **高潮：** 陳安的候選裡沒有那筆私有薪資樣式。周寧看不到陳安的私有生成紀錄。
3. 周寧把薪資樣式改成共享。陳安可以套用，不能修改。

失敗：薪資樣式仍是私有時，陳安用它的識別去產生報表。工具拒絕，讀列次數是 0。

### 管理者帳號把入口指派到帳號

安裝完成後的那一個管理者帳號。來源沒有再給這個人的名字。

1. 管理者登入，看到帳號與入口指派。
2. 建立一個操作者。表單只有顯示名稱與登入秘密。儲存後，account-row 上沒有入口徽章。
3. 在入口指派選剛才那個帳號，勾選一個或多個入口。儲存。這一步不讀業務列。
4. **高潮：** 該操作者重新登入。只有一個入口時直接進入該站。帳號頁仍然沒有入口欄位。

失敗：另一個已登入的帳號直接打開入口指派。工具拒絕，入口與帳號都保持原狀。

## 開放項

- [NOTE FOR UX] 登入還沒有具名人物的旅程。
- [NOTE FOR UX] 載入中的呈現、未儲存變更要不要擋下離開，來源都沒寫。
- [ASSUMPTION] 兩個以上入口時用換站整頁切換。只有一個入口時不出現換站。
- [ASSUMPTION] Blazor 的無障礙底線是 WCAG 2.2 AA。低於 1100px 不做手機版。
