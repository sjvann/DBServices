# 動態報表工作台

報表工作台讓三種角色分工：系統分析師定義檢視並發布，報表設計師把已發布檢視排成樣式，終端使用者用一句話產生這一次的動態報表。

列只來自 `McpService` 對該檢視的一次即時讀取。工作台不把 Web API 的列組成報表，也不在來源資料庫建立檢視。連線字串留在 MCP 宿主。

## 啟動

先啟動 MCP 宿主，再啟動工作台。兩邊的 `Workbench:CatalogKey` 必須相同，工作台的 `Surfaces:Mcp:BaseUrl` 必須指到宿主。

```bash
dotnet run --project McpService
dotnet run --project Workbench
```

工作台預設是 `http://localhost:5099`。MCP 預設是 `http://localhost:5291`，對應 `Workbench/appsettings.json` 裡的 `http://127.0.0.1:5291`。

範例組態：

```json
{
  "Workbench": {
    "SqlitePath": "workbench.db",
    "InitialAdmin": {
      "DisplayName": "管理者",
      "Password": "請改成自己的密碼"
    },
    "CatalogKey": "change-me"
  },
  "Surfaces": {
    "Mcp": {
      "BaseUrl": "http://127.0.0.1:5291"
    }
  }
}
```

帳號庫是工作台自己的 SQLite（`Workbench:SqlitePath`）。零個操作者時，會用 `InitialAdmin` 建立恰好一個管理員；之後不再讀這組初始密碼。顯示名稱或密碼空白，且還沒有操作者時，入口不會開。倉庫內的範例密碼與目錄金鑰只供本機，接到別人能碰到的位址之前請換掉。

桌面殼 `Workbench.Avalonia` 只呼叫同一座工作台 HTTP，預設基底網址也是 `http://localhost:5099`。登入狀態用 `sessionId`，不把連線字串放進殼裡。

## 環境要先完成

管理員在 `/environment` 接上資料庫，並設定模型位址。資料庫連線寫進 MCP 的連線目錄；測試連線不會寫入。模型位址寫在工作台內容根的 `model.json`，金鑰留在該檔。

這兩項都完成之前，不能定義檢視、排樣式或產生報表。產生報表時，可用連線必須恰好一筆；零筆或多筆都不會讀列。

## 三個入口

管理員在 `/operators` 建立操作者，在 `/entries` 指派入口。沒有公開註冊。一人可以同時持有多個入口；超過一個時，登入後到 `/stations` 選擇這次要做的工作。畫面一次只留下該入口。

| 入口 | 路徑 | 做什麼 |
|------|------|--------|
| 系統分析師 | `/views` | 從連線的資料表定義檢視：來源表、關聯、輸出欄、參數、用途。發布之後，該檢視才成為 MCP 工具 |
| 報表設計師 | `/styles` | 引用恰好一筆已發布檢視，排成由上到下的樣式。區塊只有標題、說明、參數、表格 |
| 終端使用者 | `/talk`、`/records` | 用一句話產生動態報表，並把這一次留下生成紀錄 |

未發布的檢視不會出現在樣式可選清單，也不會出現在 Agent 的 Discovery。樣式繫結檢視的穩定 id。被樣式引用時，不能刪除、取消發布，也不能改名稱、輸出欄、參數、來源表或關聯；用途可以改。

## 一句話產生報表

終端使用者在 `/talk` 輸入語句，例如「銷貨月報，年月 2026-10」。

工作台只在自己可讀的樣式裡比對：

1. 對不到樣式，或多份樣式同時符合：不呼叫 MCP，畫面說明對不到或多筆。
2. 檢視已不在目錄：不呼叫 MCP。
3. 語句還沒補齊該檢視的每個參數：不呼叫 MCP，並指出還缺的條件名。
4. 可用連線不是恰好一筆：不呼叫 MCP。
5. 上述都齊了：以檢視名稱呼叫 MCP 恰好一次。引數是那筆連線的 `connectionId`，以及語句裡的純量參數。

空列是成功。呼叫失敗時不產生報表，也不改既有樣式與生成紀錄。比對本身不讀業務列。

產生之後可以：

- **留下紀錄**：把這次的區塊、欄、列與參數存進生成紀錄，並指定只給自己或與其他人共享。紀錄不含連線字串。
- **存回樣式**：版面存回樣式庫，不含這次的列與參數值。
- **匯出 PDF**：依這次報表畫 A4。再開已保存的紀錄再匯出時，不再呼叫 MCP。
- **清掉這次**：未保存就離開後，不能再匯出那一份。

`/records` 列出這位終端使用者可讀的生成紀錄。私有只對擁有者；共享對終端使用者可讀。其他人不能改或刪。打開紀錄只讀當時存下的欄與列。

## 專案分工

| 專案 | 職責 |
|------|------|
| `Workbench` | 網站宿主。Blazor Server、登入與 `/api` |
| `Workbench.Web` | 頁面。不參考 MCP 套件 |
| `Workbench.Core` | 入口、樣式、語句、動態報表與生成紀錄。不參考 ASP.NET、SQLite 或 MCP |
| `Workbench.Contracts` | 兩邊殼共用的資料形狀 |
| `Workbench.Adapters` | 呼叫 MCP 目錄與檢視、寫 PDF、讀模型檔 |
| `Workbench.Storage.Sqlite` | 操作者、入口、樣式、生成紀錄 |
| `Workbench.Avalonia` | 桌面殼，只打工作台 HTTP |
| `McpService` | 檢視目錄、連線目錄與 `POST /mcp` |
