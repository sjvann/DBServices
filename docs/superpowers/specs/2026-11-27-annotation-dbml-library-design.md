# 註記前置：Excel 預設註解與連線 DBML

日期：2026-11-27

狀態：已同意，開始實作

## 目的

註記是報表工作台的前置作業。必要的資料來源是環境設定裡的資料庫連線：它提供表、欄與真正的資料，欄位通常沒有註解。Excel 字典是輔助，不一定有。有 Excel 時，用它的句子當對得上欄位的預設註解，人再補上更多說明。沒有 Excel 時，人直接在連線這份上寫註解。確認後的連線 DBML 留給檢視綁定。Excel 不拿來取數，沒有 Excel 也不阻擋讀結構或確認。

## 必要與輔助

- 要交給檢視的註記必須來自一筆資料庫連線。沒有選定可用連線時，不讀結構，也不確認成可綁定的包。
- Excel 可以完全不存在。此時連線包的欄註維持空白，由人填寫後仍可確認。
- 有 Excel 時，它只補預設註解。連線包的表與欄仍以該連線讀到的結構為準。Excel 有、資料庫沒有的欄不進連線包。

## 留檔

目錄仍是註記包，一份來源一包。

- 每包有 `sourceKind` 與 `sourceKey`。Excel 的身份是去掉路徑後的檔名，比較時不分大小寫。連線的身份是環境設定裡的連線名稱。
- 每個身份同時最多一份草稿。Excel 與不同連線可以各有一份草稿。
- 表註與欄註有 `noteOrigin`（`excel` 或 `user`）與 `noteSource`（Excel 檔名）。人一改文字，就改標成 `user`，並清掉檔名。
- 確認後的連線包可以被檢視綁定。Excel 包不出現在檢視的來源清單。
- 沒有來源身份的舊包維持原有的單一啟用規則。

## 兩種確認

- Excel：至少一張表、一個欄即可確認，不對活庫，也不要求整包說明。確認後以檔名留檔，`active` 為 false。同一檔名再確認，蓋掉該檔。
- 連線：整包說明要有內容，且至少一張表、一個欄。表名與欄名必須對得上這一筆連線。已綁定這份的檢視若會用到新包裡沒有的表、欄或關聯，拒絕確認，舊包與檢視都不改。通過後蓋掉同一連線名稱的那一份，並保留原包的 id，檢視上的綁定不用改寫。其他連線的包保持啟用。

讀結構時可以指定連線名稱（查詢參數 `connectionId`）。沒有帶這個參數時，仍沿用原本「恰有一筆、且名稱等於平台連線」的門檻。指定的名稱必須是組態完整的連線。組態鍵 `Annotation:StagingConnection` 若有值，該名稱拒絕讀取與確認。

## 合成

- 讀結構帶出表、欄、型別、主鍵與外鍵。
- 已確認的 Excel 包依表名與欄名對上，比較區分大小寫。欄上還沒有註解、也不是人寫的，且只有一份 Excel 對上時，填入該句，並標上檔名。多份對上時不自動選，欄維持空白，由人挑定後才寫進草稿。
- 人寫過的註解，再讀結構或再匯入 Excel 都不覆蓋。仍標成來自某 Excel、且人沒改過的，再讀結構時跟那份 Excel 的新註解更新。
- 資料庫有、Excel 沒有的欄留空。Excel 有、資料庫沒有的欄不進連線包。
- 同一 Excel 檔名再匯入只更新那份 Excel 包，不改連線包裡人寫過的註解。

## 檢視

- 檢視文書有 `annotationId`，指向所綁的連線包。
- 只有一份可綁定的連線包時，設計清單用它。多份時先選一份，表、欄、關聯都來自那一包，取數走該包的連線名稱。
- 連線字串留在伺服器。註記包、匯出的 DBML 與畫面不含連線字串、密碼或業務列。註解不寫回來源庫。

## 拒絕

- Excel 對不上字典契約：拒絕匯入，該檔名已留的包不變。
- 指定的連線不存在或組態不完整：不讀結構，草稿不變。
- 連線確認對不上表名或欄名：拒絕，草稿與已確認包都不改。
- 已綁定檢視會落到新包之外：拒絕，訊息列出檢視名稱。
- 上述拒絕都不讀業務列。

## 驗收

- 同一 Excel 檔名、同一連線名稱，各只留一份已確認包，並可匯出對得上內容的 DBML。
- 沒有任何 Excel 包時，從連線讀入的欄註維持空白；人補上整包說明後可以確認，檢視綁得到這份連線包。
- 只有一份 Excel 對上的欄會自動填入並標檔名；多份時該欄維持空白。沒有對上的欄維持空白。
- 人補上的說明在再讀之後仍在。
- 檢視只能綁已確認的連線包。Excel 包不進檢視來源清單。
- 任一拒絕發生時，既有草稿、已確認包與檢視維持原樣。
