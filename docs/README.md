# 文件（DocFX）

概念文件與 API 參考的來源。建置產物在 `_site/`，請勿提交。

```bash
dotnet tool restore
dotnet docfx docs/docfx.json --serve
```

線上：[https://sjvann.github.io/DBServices/](https://sjvann.github.io/DBServices/)

概念頁包含入門、指南、CLI、Web API、GraphQL、MCP 與動態報表工作台。維護說明見 [contributing/documentation.md](contributing/documentation.md)。
